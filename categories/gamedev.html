Match Card Game (Unity)

  • • Unity Engine (C#)
  • • Dynamic grid generation system
  • • Grid validation for playable layouts
  • • Card shuffling & matching logic
  • • Simple UI flow and menu design

A small card‑matching game built in Unity. Players select a grid size from the main menu, and the game validates the layout before generating a shuffled board. Includes five card types, grid limits up to 6×10, and a lightweight UI designed for desktop builds.
